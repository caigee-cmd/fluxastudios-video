# Fluxa 积分说明（前端展示）

这是用户可见文案与展示口径的说明，不改计费引擎、报价公式、充值商品或生产价格。相关界面改动还没有随本文档自动上线。

## 已经说明什么

- **默认兑换**：本站用户约定为 1 元人民币 = 1 积分，积分支持小数（后端以微积分整数记账，1 积分 = 1,000,000 微积分）。
- **实际到账**：充值页展示选中商品的支付金额和 `creditsMicrocredits`。仅当人民币积分套餐的到账微积分等于 `amountFen * 10,000` 时，才写「与默认 1 元 1 积分一致」；赠送或促销包不得无条件承诺 1:1。
- **生成估价**：创作页作曲器和画布节点提示条复用现有 `quoteModel` / `/models/{id}/quote` 与 `/model-catalog/quote`。参数变化会取消进行中的询价，不闪现上一笔报价；加载中或无法估算时不把空值显示成 0 积分免费。未走服务端询价的部分直连图文档位仍可展示本地配置价。
- **流水与任务计费**：预冻结、成功结算、明确失败退回、待核对。明确失败且没有成功计费证据时退回冻结积分；上游成功但本地保存失败，或超时等状态不明时进入待核对，不会自动当作失败退款。明细只展示流水里真实存在的模型、场景和备注，不编造分辨率或时长。

## 覆盖范围

- 已覆盖：钱包充值页、积分消耗历史、创作页作曲器（图/视频/文，同一入口）、画布节点生成按钮旁估价、任务中心/画布任务计费胶囊的说明。
- 未在本次改动：电商 Agent、图片工作台独立估价、短剧预算条、画布视频增强对话框、模型选择器价格芯片、素材组认证扣费说明等其它入口。那些入口仍使用各自原有报价或金额展示。

## 未定政策（不要在界面或运维文档里编造承诺）

代码里没有面向用户的积分有效期、余额提现或充值资金退款规则。管理后台支付工具里的「平台不提供支付退款」是对账/关单说明，不能改写成用户协议里的「充值概不退款」。未正式公布前，界面只写「尚未公布，不作承诺」。

存储扩容可能显示「永久」，那是存储授权，不是积分有效期。

## 以后配置时要注意

- 若要保持人民币积分套餐与默认 1 元 1 积分一致，上架时设置 `CreditsMicrocredits = AmountFen * 10,000`。促销或多给积分的套餐可以不同，但商品卡片和到账说明必须以该套餐的到账数为准。
- 不要在前端或文档里写死某一模型（包括 MiniMax H3 等）的售价；售价以管理后台价格档位和报价接口为准。
- 「待核对订单自动退回」是管理开关，默认关闭。打开前要理解范围：不是所有失败都会立即退款。
- 修改钱包/创作积分文案时，同步 `web/src/i18n/messages/areas/account/` 与 `web/src/i18n/messages/areas/create/` 的全部语言文件。
